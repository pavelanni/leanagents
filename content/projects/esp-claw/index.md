## Key features

- MCP server and client
- On-chip long-term memory
- Hybrid execution: LLM for dynamic decisions, Lua for
  deterministic tasks
- Offline operation
- Millisecond response times for cached behaviors
- Chat-as-coding paradigm for IoT devices
